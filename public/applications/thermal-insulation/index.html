APPLICATION GUIDE

Define the thermal objective and the building element.

HiBAR is used to add thermal resistance in building assemblies. The design must address the actual construction and conditions of the project.

Describe the construction

Include drawings, the substrate, the proposed location of insulation and any known limitations or existing conditions.

Request project-specific information

Confirm the proposed thickness and performance using current manufacturer information and the project designer. Do not substitute a generic value for a design.
